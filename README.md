# Life Style Mentor Bot 🤖

**Личный Telegram-бот** — ежедневный ментор, трекер настроения, тренировок и веса.

Помогает вести дневник, получать честную обратную связь от ИИ и отслеживать прогресс в жизни и спорте.

---

## Возможности

- Ежедневные отчёты о дне + оценка настроения (1–10)
- ИИ-ментор с честными комментариями и рекомендациями
- Трекинг тренировок (настроение до/после, описание упражнений)
- Графики изменения настроения и веса
- Статистика за неделю и месяц
- Вечерние напоминания
- Поддержка Docker

---

## Технологии

- Python 3.12
- aiogram 3.x
- PostgreSQL + psycopg
- APScheduler
- Matplotlib
- Docker

---

## Быстрый старт

### 1. Через Docker (рекомендуется)

```bash
# Клонируем репозиторий
git clone https://github.com/moly3233/life_style_bot.git
cd life_style_bot

# Копируем шаблон переменных окружения
cp .env.example .env

# Заполняем .env файл своими данными

# Запускаем бота
docker build -t lifestyle-bot:latest .
docker compose up -d
